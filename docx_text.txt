🤖  1. Master AI System Prompt

To generate future documents matching this exact visual system, copy and paste the prompt block below into any advanced AI model (Gemini, Claude, ChatGPT, or Antigravity). It enforces all layout geometry, color codes, table styling, and single-page module budgets.

[COPY & PASTE THIS MASTER PROMPT TO CREATE DOCUMENTS IN THIS FORMAT]Act as an expert Document Architect and Visual Designer. Generate an executive, enterprise-grade Word (.docx) document adhering strictly to the following Design System:1. PAGE GEOMETRY & LAYOUT- Page Size: US Letter (8.5" x 11" / portrait).- Margins: 1.0 inch (72pt) uniform on all sides (Top, Bottom, Left, Right).- Content Width: 6.5 inches (468pt). All tables and cards MUST span 100% of this width.- Strict Page Budgeting: Every major section or functional module MUST fit cleanly on exactly ONE page, delimited by a hard page break. Never allow orphan headings or split tables.2. COLOR PALETTE (Tailwind Slate/Teal Enterprise Theme)- Primary Dark: #0F172A (Slate 900) - for headings, main hero card, and table key labels.- Primary Accent: #0D9488 (Teal 600) - for table header fills, primary dividers, and badges.- Secondary Accent: #2563EB (Blue 600) - for date/version card highlights.- Body Text: #475569 (Slate 600) - for paragraphs and table descriptions.- Table Row Tint: #F0FDFA (Teal 50) - for alternating odd table rows.- Base White: #FFFFFF - for canvas, table header text, and alternating even rows.- Dividers: Single solid lines: #0D9488 (0.75pt) and #E2E8F0 (0.75pt).3. COVER PAGE ARCHITECTURE- Hero Banner Card: 1x1 table shaded #0F172A containing Title (30pt Bold White + 🏠 emoji), Sub-brand (24pt Bold #0D9488), and Subtitle (12pt #CCFBF1).- Metadata Card Cluster: 1x3 table with zero gaps. Card 1: #0D9488 (Author), Card 2: #0F172A (Org), Card 3: #2563EB (Date/Version). White bold text with #E2E8F0 labels.- Dual Dividers & Navigation Bar: Centered navigation pills flanked by #0D9488 and #E2E8F0 divider lines. Hard page break to Page 2.4. TABLE OF CONTENTS- 3-column table: Column 1 (0.5"): #0D9488 bold index number; Column 2 (2.8"): #0F172A bold section title; Column 3 (3.2"): #475569 description. Zebra striping with #F0FDFA and #FFFFFF.5. INTERIOR MODULE PAGES- Heading (H1): 18pt Bold #0F172A preceded by an entity-specific emoji glyph and section number (e.g., 📋 2. Leads Module).- Context Narrative: 1-2 sentence lead paragraph in 10pt #475569 explaining purpose and governance.- Data Table: 100% borderless table (tblBorders: none). Header row shaded #0D9488 with 10pt Bold White text. Alternating rows (#F0FDFA / #FFFFFF). Column 1 bold #0F172A; Column 2 regular #0F172A; Column 3 regular #475569.6. PROCESS FLOW DIAGRAMS- Pure-text vertical stepper: Centered step title in 11pt Bold #0D9488, 9pt subtitle in #475569, connected by centered ▼ glyphs in 11pt Bold #0D9488.Output the complete, fully formed document using python-docx with precise OpenXML element formatting.

📊  4. Table Engineering & Workflow Steppers

Tables and vertical steppers constitute the core visual mechanics of this design system. Both must follow strict XML configuration rules.

⚙️  Table Construction Rules

Engineering Rule

OpenXML Implementation

Visual / Functional Result

Zero Borders (Border-Free)

tblBorders set to val='none'

Eliminates heavy gridlines for a clean, modern aesthetic.

Solid Teal Header

tcPr/w:shd w:fill='0D9488'

High-contrast anchor with pure white bold typography.

Zebra Row Striping

Odd: #F0FDFA, Even: #FFFFFF

Provides effortless horizontal scanning across data columns.

Vertical Cell Margins

top='140' bottom='140' dxa

Ensures consistent cell breathing room (approx. 7pt padding).

Paragraph Spacing in Cells

before='50' after='50' dxa

Maintains tight vertical rhythm without awkward line jumps.
